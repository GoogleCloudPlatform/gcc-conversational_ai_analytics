# Looker Blocks for Conversational AI Analytics

This directory contains Looker blocks that you can use to visualize the data from your Conversational AI Analytics pipeline.

## Available Blocks

- **`conversational_agents_block`**: A Looker block for visualizing the structure and configuration of your Dialogflow CX agents.
- **`insights_looker_block`**: A Looker block for analyzing conversation data from CCAI Insights.

## How to Use

Each block has its own `README.md` file with detailed instructions on how to install and use it.
